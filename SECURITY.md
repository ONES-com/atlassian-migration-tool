# Security

We welcome reports that help keep the ONES Migration Tool safe and reliable.

For general questions, reproducible product behavior, package download problems, and documentation feedback, GitHub Issues and Discussions are appropriate.

If your report involves a possible security vulnerability, sensitive data, access control, credentials, secrets, logs, or customer environment details, [contact ONES privately](https://ones.com/contact_us/migration). This helps the team review the issue without exposing information that should not be public.

When contacting ONES, include:

- ONES deployment type and version
- Migration Tool version
- Source product and deployment type
- A concise description of the issue
- Steps to reproduce, if available
- Relevant logs or screenshots with secrets and customer data removed

Never post passwords, tokens, cookies, private keys, private URLs, customer data, or unredacted logs in public GitHub Issues or Discussions.
