## Availability

- Package: Linux AMD64
- Target deployment: ONES Self-Hosted
- Minimum supported ONES version: 7.80.0

## Release Notes

- Requires ONES Self-Hosted 7.80.0 or later. The tool checks the ONES version at login and blocks connections to earlier versions.
- Version guidance on the Jira home page and Confluence migration page now matches this minimum requirement.

## Install and Use

Follow the [Migration Tool Guide](https://docs.ones.com/import-data-into-ones/migration-tool-guide/?utm_campaign=github-ones-com&utm_content=ONESMigrationTool&utm_medium=onesgithub&utm_source=github) for preparation, startup, connectivity checks, migration steps, attachment copying, and index rebuilding.

For ONES versions earlier than 7.80.0, [contact ONES](https://ones.com/contact_us/migration/?utm_campaign=github-ones-com&utm_content=ONESMigrationTool&utm_medium=onesgithub&utm_source=github) to confirm an appropriate tool version before starting.

For Jira Cloud to ONES Self-Hosted migrations, [contact ONES](https://ones.com/contact_us/migration/?utm_campaign=github-ones-com&utm_content=ONESMigrationTool&utm_medium=onesgithub&utm_source=github) before starting.
