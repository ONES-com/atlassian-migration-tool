# Support

Choose the channel that matches your request.

## Migration Questions and Planning

[Contact ONES](https://ones.com/contact_us/migration/?utm_campaign=github-ones-com&utm_source=github&utm_medium=onesgithub&utm_content=ONESMigrationTool) for:

- Migration planning questions
- Choosing a migration path or data-source method
- General product questions
- Ideas and use cases

## GitHub Issues

Use [Issues](https://github.com/ONES-com/atlassian-migration-tool/issues) for:

- Reproducible migration problems
- Installation or startup problems
- Package download problems
- Documentation corrections
- Specific feature requests

Include the Migration Tool version, ONES version, source product and deployment type, expected behavior, actual behavior, and reproduction steps when possible.

## Private ONES Support

[Contact ONES](https://ones.com/contact_us/migration) when your request includes customer environment details, sensitive data, credentials, private URLs, unredacted logs, or migration assistance that should not be discussed publicly.
